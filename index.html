RunSkeleton

A reusable skeleton template for governed AI experiment runs — built with Kiro specs, steering and hooks. Kiroween 2026 · Skeleton Crew.

App 1 — Experiment Ledger Viewer

Browse an append-only, hash-chained experiment ledger: proposals, admissions, gate verdicts, promotions and rollbacks.

App 2 — Paired Evaluation Dashboard

Champion vs challenger, pair by pair: per-pair deltas, mean paired difference, and the promotion gate read-out.

The template itself is a zero-dependency Python CLI (template/skeleton.py) that initializes a governed run, records ledger entries, and verifies the hash chain. Full documentation is in the repository README.
